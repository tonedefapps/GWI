# GWI (Get Waved In)

Site for **Waved In**, a ToneDef Apps product, served at https://getwavedin.com by GitHub Pages.

- `index.html` -- landing page
- `beta/` -- hand-run beta intake (resume upload posts to a Google Apps Script that saves to Scott's Drive)
- `assets/` -- brand kit: wordmark, badge, mark, app icons, favicon, hero art (red-eyed "before" variants included)
- `CNAME` -- custom domain for GitHub Pages

A copy also lives at tonedefapps.com/getwavedin in the tonedefmain repo.
